# Magic Time Events — Real Photo Asset Pack

These are the actual photos pulled out of your portfolio PDF (full resolution,
not screenshots), organized so you — or Claude Code — can drop them straight
into the new website.

## Folders

- **logo/** — `magictime-logo.jpg`: your gold crest logo, square, on black.
  Works as-is on any dark background. Ask your designer for a transparent
  PNG version if you ever need it on a light background.
- **hero/** — `hero-stage-crowd.jpg`: the big concert/crowd shot from your
  cover slide. Note: this file already has the orange circle graphic and
  black letterboxing baked in from the original slide — either crop the
  black bars off, or just recreate the orange-circle overlay in code (the
  website prompt does this) and use a cleanly-cropped version of this photo.
- **gallery/concerts-artists/** — stage, lighting, pyro and artist shots for
  your "Concerts & Festivals" portfolio category.
- **gallery/college-fests/** — BJB Fiesta and similar college-event photos,
  aerial venue shots, crowd shots.
- **gallery/corporate-government/** — dignitary, ribbon/garland, speaker and
  formal-audience shots for your "Corporate & Government" category.
- **gallery/production-infrastructure/** — tent/hanger structures, mixing
  consoles, LED walls, and the 3D venue concept render.
- **gallery/decor-design/** — floral entrance and prop/installation shots.

## Notes

- One stock-looking photo from the "Our Mission" slide (a crowd watching
  fireworks near what looks like the Eiffel Tower) was deliberately left out
  — it doesn't look like one of your own event photos, so it's safer for you
  to confirm its license before using it, or just swap in one of your own.
  There's a genuinely dramatic Odisha crowd shot on hand for the mission
  section without it — use `gallery/concerts-artists/bw-crowd-stage-wide.jpg`
  instead, framed the same way, in black and white.
- File names are descriptive but generic (I couldn't always tell which exact
  event/client each photo is from) — rename freely once they're in your
  project.
- Total pack size: ~4.5MB, 35 photos. Feel free to compress further for web
  (the build prompt already asks Claude Code to do this).
